About the Project

Optimized CNN for Pneumonia Detection

A final year undergraduate research project at the Federal University Oye-Ekiti, Department of Computer Science.

The Problem

Pneumonia is responsible for over 2.5 million deaths annually and kills a child every 39 seconds worldwide. In resource-limited settings like Sub-Saharan Africa, a shortage of radiologists means many cases go undiagnosed.

Chest X-ray remains the standard first-line imaging tool, but interpretation requires trained specialists and even among experts, disagreement occurs in up to 30% of cases.

The Solution

This project develops OptCNN — a custom Convolutional Neural Network for binary classification of chest X-ray images into Normal and Pneumonia categories.

With only ~2.8 million parameters, OptCNN outperforms transfer learning giants like VGG16 (138M parameters) while being more suitable for resource-constrained environments.

OptCNN Architecture Summary
Block 1:Conv2D(32) x 2 + BN + MaxPool + Dropout(0.25)
Block 2:Conv2D(64) x 2 + BN + MaxPool + Dropout(0.25)
Block 3:Conv2D(128) x 2 + BN + MaxPool + Dropout(0.30)
Block 4:Conv2D(256) x 2 + BN + MaxPool + Dropout(0.30)
Head:GAP + Dense(256) + BN + Dropout(0.5) + Sigmoid
